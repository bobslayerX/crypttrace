How it works

The graph maps where funds moved, hop by hop. Nodes are coloured by what they are — exchanges are cash-out points, mixers break the trail.

Protocol

  1. Enter the address the funds were sent to.
  2. Trace outward for cash-out, or inward for the source.
  3. Click a node for profile, first-funder and off-ramp.
  4. If an exchange appears, contact them with the case file.
